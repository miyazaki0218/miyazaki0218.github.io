04LabJavaScript作品

業務とは別に、JavaScriptの練習として自分で作ったものです。実際に動かせます。

  • LAB 01

    郵便番号から住所を自動入力

    お問い合わせフォームでよく使う機能です。郵便番号を入れてボタンを押すと、外部APIから住所を取得して住所欄に入力します。見つからない番号や桁数の間違いにはメッセージを出します。

    • JavaScript
    • fetch
    • async / await
    • 郵便番号検索API
    デモを見る↗

  • LAB 02

    WordPressの記事を読み込む

    WordPress REST APIから記事を取得して、一覧を表示します。件数を選んで読み込めます。WordPressの外（LPや別サイト）に、ブログの新着記事を出すときに使える仕組みです。

    • JavaScript
    • fetch
    • map
    • WordPress REST API
    デモを見る↗
